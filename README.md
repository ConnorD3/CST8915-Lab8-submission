### Task 2: 

1. Azure Service bus is Azure's managed message broker service, like RabbitMQ it facilitates message transfer between applications and services. This service is fully managed by Azure, is serverless, and can take advantage of Azure autoscaling unlike RabbitMQ, which significantly reduces the overhead of message handling.
2. Azure DocumentDB is a managed document database that stores data in a json format rather than in tables. DocumentDB is a good replacement as it is stated to reduce costs up to 40% when compared to MongoDB, and includes free backups, and no extra egress charges, making its main benefits being significantly cheaper than an unmanaged alternative.
